# Snack Quests

Studio storefront for **Snack Quests**, an independent micro gaming studio.

Bite sized educational and faith based games for mobile browsers, the kind you can play on a 10 minute car ride or in a waiting room. For now, pay what you like. In the future, the only prices will be $0.99 to $2.99. No surprise prices. No pop up ads, no hidden trackers, no surprise microtransactions.

## This repository

This repo is the public static storefront (HTML, CSS, and a little JavaScript). There is **no build step**. GitHub Pages serves the site from the default branch (`main`) at the repository root.

- GitHub Pages: https://chearst444.github.io/snackquests/
- Custom domain: [snackquests.com](https://snackquests.com)
- Source: [github.com/chearst444/snackquests](https://github.com/chearst444/snackquests)

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server
```

Asset URLs are relative so the site works both at the domain root and at `/snackquests/`.
